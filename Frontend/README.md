# coinBee — Frontend

The client-side application for **coinBee**, built with React 19, Vite, and Tailwind CSS v4, inspired by the **Rocket Money** fintech design system.

For full project documentation, architecture, and setup instructions, refer to the root [README.md](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
